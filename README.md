# 資料科學作品集｜Data Science Portfolio


本作品集收錄三個端到端的資料科學專案，聚焦於「以商業問題定錨、以理論驅動特徵工程、以嚴謹方法論避免資料洩漏與統計陷阱」的實作。每個專案皆附完整報告 PDF 與可於 GitHub 直接閱讀的 README。

---

## 專案列表

### 1. [電商分眾決策模擬系統](01-ecommerce-segmentation/)

以雙層漏斗機器學習架構與動態決策門檻，從 9 萬名電商訪客的 GA4 行為資料中識別加車與購買意圖，將流失用戶精準分層挽回，取代一刀切補貼。

`GA4` · `BigQuery ML` · `Dataform` · `XGBoost` · `SHAP` · `Python`

重點：雙漏斗分層建模、時序切分與截斷點防漏、F1-max 動態門檻、分眾補貼經濟（breakeven uplift）、A/B Incrementality 設計。

### 2. [電信用戶流失分析與留存策略](02-telecom-churn/)

以邏輯斯迴歸嚴謹控制混淆變數，破解「高月費 ＝ 高流失」的辛普森悖論，量化合約、加值服務與網路類型對流失的獨立效果。

`Python` · `EDA` · `Logistic Regression` · `Statsmodels`

重點：混淆變數控制、辛普森悖論、勝算比（Odds Ratio）與信賴區間、留存死亡谷、可落地的留存策略。

### 3. [展店選址智慧系統](03-retail-site-selection/)

結合政府開放資料與機器學習，為連鎖零售打造科學化展店決策系統；主導文獻回顧、特徵工程、資料庫（ER Model）設計與 EDA。

`XGBoost` · `MySQL` · `ER Modeling` · `Geospatial` · `Open Data` · `Gemini LLM`

重點：多源異質資料整合、三階段漸進式建表、相對比例特徵、防資料洩漏、雙軌推薦門檻、LLM 洞察報告。

## 共通方法論主軸

| 主軸 | 具體實作 |
| --- | --- |
| 理論驅動 | 以消費者行為／零售選址／轉換成本等文獻定錨特徵選擇 |
| 防資料洩漏 | 時序切分、時間截斷點、剔除高基數與滲漏特徵 |
| 統計嚴謹 | 混淆變數控制、共線性診斷（VIF／相關矩陣）、勝算比與信賴區間 |
| 可解釋性 | SHAP 特徵歸因、係數與商業語意對接 |
| 商業落地 | 動態門檻、分眾策略、補貼經濟推導、A/B 驗證設計 |

## 使用說明

每個專案資料夾包含：

- `README.md`：可於 GitHub 直接閱讀的完整報告（含圖表、結果與程式碼連結）。
- `assets/`：報告中的圖表。
- `code/`：代表性程式碼節錄（`.sql` / `.py`），供快速檢視技術實作。

> 說明：`code/` 收錄的是**代表性節錄**而非完整程式，部分邏輯仍留在 BigQuery／GCP／MySQL 環境中，未全數搬出。
